A one-page newspaper image (1024×1024) that sums up the world on **Saturday 21 November 2026** — every story date-verified, no Friday leftovers.

## What's inside

- **37 stories, 10 regions** — 3 lead stories + 10 features + 24 briefs, covering the globe in a single day.
- **3 lead stories:** Iran strikes US bases in Bahrain, a deep earthquake in Peru, and COP31 going into overtime.
- **Numbered map** — every story is pinned to a numbered marker on the world map so you can see where it happened at a glance.
- **DATE CHECK box** — a visible check on the page confirming all 37 stories are dated Saturday 21 November 2026. Nothing from Friday 20 November made it in.

## Run it

```bash
python3 main.py
```

That regenerates `entry.png` (1024×1024) from the dated story set.
